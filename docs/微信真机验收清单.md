## 四、已知限制（验收时会遇到）

- **AppID 是 Cocos 默认测试号**：真机预览需要你注册的小游戏 AppID + 已开通「游戏」类目；否则只能模拟器验收
- **广告触点**：`adunit-debug-feed` 是占位符——模拟器/未配置广告位时会走 fail 分支提示"广告加载失败"（属预期）；上线前在 mp 后台创建激励视频广告位并替换
- **wx-login 需要真实 code2session**：服务端 `WX_APPID/WX_SECRET` 未配置时 wx-login 会降级，模拟器登录可能拿不到正式 openid（`.env` 配置后才走通全链路）
- **code2session 备案域名**：真机 release 版必须 https 合法域名，开发期靠"不校验合法域名"绕过
