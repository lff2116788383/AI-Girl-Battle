## 首次打开步骤（约 3 分钟）

1. 打开 **Cocos Dashboard → 项目 → 导入本地项目**，选择 `AI-Girl-Battle/client`（引擎选 3.8.7）
2. 首次打开编辑器会自动生成 `library/`、`temp/`、各资源的 `.meta`（属正常现象，均已 gitignore）
3. 新建场景：资源管理器 → `assets/scenes` 右键新建场景，命名 `home`
4. 场景里：删掉默认灯光（2D 不需要），保留 **Canvas**
5. Canvas 属性检查器 → 挂载两个组件：`GameManager`、`HomeUI`
6. Canvas 设计分辨率建议 **720×1280（竖屏）**：Canvas → Align Canvas Widget 或项目设置里改设计分辨率
7. `Ctrl+S` 保存场景 → 点击 ▶ 预览

> 首帧图片是动态加载（`resources.load`），点预览后在浏览器里即可看到完整家园界面。

## 已实现功能（家园闭环）

| 功能 | 说明 | 代码入口 |
|---|---|---|
| 首批阵容 | 3 部署（小深/小蓝/鲸尾）+ 1 租用（租用·鲸鲸 7天） | `HomeModel.initFirstRun` |
| 四设施升级 | 宿舍/电闸/风扇/小厨房 各 2 级，金币扣费 | `HomeModel.upgradeFacility` |
| 负载实时显示 | 床位/供电/散热 超载预警（卡片上直接看） | `HomeModel.powerUsed` 等 |
| 每日结算 | 电费→饲料→工资→散热→心情→离线收益，含跳闸/断粮/过热/离场事件 | `SettlementEngine.computeSettlement` |
| 结算预览 | 不落盘先看账单 | `HomeUI.onPreview` |
| 调试拨快 | +1 天按钮，免等待验证结算 | `HomeModel.debugAdvanceDays` |
| 冰垫救援 | 点击过热 AI 娘消耗冰垫解救 | `HomeModel.rescueOverheat` |
| 帧动画立绘 | 待机/蔫/宕机 三态自动切换 | `PetView.playStatus` |
| 双平台适配 | wx.setStorageSync / localStorage 自动切换 | `WxAdapter` |

## 数值表（v0，改 balance 只动 JSON）

- `assets/resources/config/facilities.json`：设施容量与升级费用
- `assets/resources/config/pets.json`：种族四维 + upkeep 养护常数（功耗/热度/饲料/工资）
- `assets/resources/config/settlement.json`：离线封顶/跳闸时长/心情阈值

> 规则：SettlementEngine 是纯函数（无 cc 依赖、无 Math.random、可播种 PRNG），
> 服务端 Go 版按同一规则表实现后做对拍测试（方案文档风险#1）。
