## 运行方式

### 方式一：编辑器预览（推荐日常开发）
1. 打开 **Cocos Dashboard → 项目 → 导入本地项目**，选择 `AI-Girl-Battle/client`（引擎选 3.8.7）
2. `assets/scenes/home.scene` 已生成（竖屏 720×1280，含 Canvas/Camera），双击打开
3. 点击 ▶ 预览 —— **无需手动挂任何组件**：`Bootstrap.ts` 会在场景加载后自动创建 HomeRoot 并挂载 HomeUI

### 方式二：命令行构建 H5
```bash
# ⚠️ 必须清除 ELECTRON_RUN_AS_NODE 环境变量（宿主工具常泄漏此变量，会让编辑器变成纯 Node 模式）
env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS \
  CocosCreator.exe --project <client目录> --build "platform=web-mobile;debug=true"
# 产物在 client/build/web-mobile，用任意静态服务器打开即可
python -m http.server 8899 --directory client/build/web-mobile
```

已验证运行截图：`docs/家园系统首运行截图.png`（60 FPS / 47 DrawCall / 纹理 18MB）

## 数值表（v0，改 balance 只动 JSON）

- `assets/resources/config/facilities.json`：设施容量与升级费用
- `assets/resources/config/pets.json`：种族四维 + upkeep 养护常数（功耗/热度/饲料/工资）
- `assets/resources/config/settlement.json`：离线封顶/跳闸时长/心情阈值

> 规则：SettlementEngine 是纯函数（无 cc 依赖、无 Math.random、可播种 PRNG），

## 已踩坑记录（2026-11-23 首次运行调试）

1. **ELECTRON_RUN_AS_NODE 环境泄漏**：宿主 CLI 工具设置的该变量会让 CocosCreator.exe 退化成纯 Node（报 `bad option: --project`），启动前必须 `env -u ELECTRON_RUN_AS_NODE`
2. **枚举 tree-shake**：构建产物中 `import { HorizontalAlign } from 'cc'` 会是 undefined，枚举一律用类命名空间（`Label.HorizontalAlign.XXX` / `Label.Overflow.XXX` / `Sprite.SizeMode.RAW`）
3. **UI 必须挂 Canvas 下**：2D UI 世界坐标基准是 Canvas 中心（360,640），挂场景根会整体跑出屏幕
4. **动态加载资源必须在 `resources/` 目录下**，且切片 PNG 的 meta 只有 texture 子资产——用 `resources.load(path + '/texture', Texture2D)` 后运行时构造 SpriteFrame
5. **agent-browser daemon 随 Bash 会话生灭**：多步骤浏览器操作必须在同一次调用内完成
